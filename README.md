## 👩🏻‍💻 Sobre mim

Estudante do segundo semestre de Engenharia de Software na FIAP. Nessa minha trajetória acadêmica, venho desenvolvendo projetos que combinam **programação, Inteligência Artificial, pesquisa com usuários, Design Thinking e metodologias ágeis**, buscando compreender o problema antes de propor uma solução. Tenho como objetivo ampliar continuamente meus conhecimentos em tecnologia, desenvolver soluções cada vez mais eficientes e construir uma base profissional sólida por meio de projetos, aprendizado prático e evolução constante!
